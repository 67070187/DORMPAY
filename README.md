# DORM-PAY ระบบจ่ายค่าหอพัก

ระบบจัดการหอพักและรับชำระค่าหอ เจ้าของหอจดมิเตอร์น้ำ-ไฟ แล้วระบบออกบิลให้อัตโนมัติ
ผู้เช่าสแกน **QR PromptPay** แล้วกด "โอนเงินเสร็จสิ้น" ระบบเปลี่ยนบิลเป็น "ชำระแล้ว" ทันที ไม่ต้องแนบสลิป
(การชำระเงินเป็น**โหมดสาธิต** ไม่มีการตรวจสอบเงินเข้าจริง)

**เทคโนโลยี:** Next.js 15 (App Router, TypeScript) · Prisma · MySQL 8 · Tailwind CSS · qrcode · Recharts

## ฟีเจอร์

**เจ้าของหอ (admin)**
- Dashboard: รายรับรายเดือน (กราฟ), ยอดค้างชำระ, อัตราเข้าพัก, รายการบิลค้าง
- จัดการห้องพัก (เพิ่ม / ลบห้องว่าง / แก้ค่าเช่า)
- จัดการผู้เช่า (เพิ่ม, ย้ายห้อง, ย้ายออก, รีเซ็ตรหัสผ่าน)
- จดมิเตอร์น้ำ-ไฟรายเดือน → คำนวณหน่วยและออกบิลอัตโนมัติ
- ดูบิลทั้งหมด กรองตามเดือน / สถานะ (รอชำระ, เกินกำหนด, ชำระแล้ว)
- ตั้งค่าอัตราค่าน้ำ ค่าไฟ วันครบกำหนด และหมายเลขพร้อมเพย์

**ผู้เช่า (tenant)**
- ดูห้องของตัวเอง ยอดค้างชำระ และรายละเอียดบิล (ค่าเช่า / น้ำ / ไฟ)
- ชำระด้วย QR PromptPay: ปุ่ม **บันทึก QR** (เซฟเป็นรูป) และปุ่ม **โอนเงินเสร็จสิ้น**
- ดูประวัติการชำระ

## วิธีติดตั้งและรัน

ต้องมี **Node.js 20+** และ **MySQL 8** (ใช้ Docker หรือ XAMPP ก็ได้)

```bash
npm install
cp .env.example .env
```

### 1. เปิดฐานข้อมูล

**แบบ Docker:** `docker compose up -d` (MySQL ที่พอร์ต 3307, Adminer ดูข้อมูลที่ http://localhost:8081)

**แบบ XAMPP:** สร้างฐานข้อมูลชื่อ `dormpay` แล้วแก้ `.env` เป็น
`DATABASE_URL="mysql://root:@localhost:3306/dormpay"`

### 2. สร้างตารางและข้อมูลตัวอย่าง

```bash
npm run db:push    # สร้างตารางจาก prisma/schema.prisma
npm run db:seed    # ใส่ข้อมูลตัวอย่าง (10 ห้อง, 7 ผู้เช่า, บิลย้อนหลัง 6 เดือน) — รันซ้ำได้เพื่อรีเซ็ตข้อมูล
```

### 3. รัน

```bash
npm run dev
```

เปิด http://localhost:3000

## บัญชีทดสอบ

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| เจ้าของหอ | `admin` | `admin1234` |
| ผู้เช่า | `tenant1` – `tenant7` | `tenant1234` |

ผู้เช่าที่มีบิลค้างในข้อมูลตัวอย่าง: `tenant3`, `tenant6`

## ลองใช้งาน (เดโม)

1. ล็อกอิน `admin` → เมนู **จดมิเตอร์** → กรอกเลข "ครั้งนี้" ของห้อง 101 → **บันทึกและออกบิล**
2. ออกจากระบบ ล็อกอิน `tenant1` → เห็นบิลเดือนนี้ → **ชำระเงิน** → ขึ้น QR PromptPay ตามยอดบิล
3. กด **บันทึก QR** เพื่อเซฟรูป หรือกด **โอนเงินเสร็จสิ้น** → ขึ้นเลขอ้างอิง บิลเปลี่ยนเป็น **ชำระแล้ว**
4. ล็อกอิน `admin` อีกครั้ง → Dashboard ยอดรับชำระเพิ่มขึ้น และดูเลขอ้างอิงได้ในหน้ารายละเอียดบิล

## การชำระเงิน (โหมดสาธิต)

```
ผู้เช่ากด "ชำระเงิน"
   → เซิร์ฟเวอร์สร้างข้อความ PromptPay ตามมาตรฐาน EMVCo (หมายเลขพร้อมเพย์ + ยอดบิล + CRC16)
   → แสดงเป็น QR Code ใน popup (แอปธนาคารอ่านได้ แต่หมายเลขเป็นของสาธิต)
   → กด "โอนเงินเสร็จสิ้น" → บันทึก Payment พร้อมเลขอ้างอิง + เปลี่ยน Bill เป็น PAID
```

- เป็นการ**จำลอง** ระบบไม่ได้ตรวจว่ามีเงินเข้าจริง ระบบจริงต้องเชื่อมกับธนาคารหรือ payment gateway เพื่อยืนยันยอด
- เปลี่ยนหมายเลขพร้อมเพย์และชื่อบัญชีได้ที่หน้า **ตั้งค่า** (ค่าเริ่มต้น `0812345678`)
- กดซ้ำไม่บันทึกซ้ำ: อัปเดตบิลด้วยเงื่อนไข `status = UNPAID` ภายใน transaction
- โค้ดสร้าง QR: `src/lib/promptpay.ts` · หน้าต่าง QR: `src/components/PromptPayModal.tsx`

## โครงสร้างฐานข้อมูล

- **User** ผู้ใช้ (role = ADMIN / TENANT)
- **Room** ห้องพัก มีผู้เช่าได้ 1 คน (`tenantId`)
- **MeterReading** เลขมิเตอร์น้ำ-ไฟ ต่อห้องต่อเดือน
- **Bill** บิลรายเดือน ต่อห้องต่อเดือน (เก็บอัตราที่ใช้คิด ณ ตอนออกบิลไว้ด้วย)
- **Payment** การชำระเงิน (เลขอ้างอิง, ช่องทาง, เวลา)
- **Setting** อัตราค่าน้ำ ค่าไฟ วันครบกำหนด หมายเลขพร้อมเพย์

> เงินทุกช่องเก็บเป็น **สตางค์** (จำนวนเต็ม) เพื่อเลี่ยงปัญหาทศนิยม

## โครงสร้างโค้ด

```
prisma/schema.prisma        โครงสร้างฐานข้อมูล
prisma/seed.ts              ข้อมูลตัวอย่าง
src/middleware.ts           กันหน้า /admin และ /tenant ตามบทบาท
src/lib/                    auth (JWT cookie), billing, promptpay, format
src/app/login               หน้าเข้าสู่ระบบ
src/app/admin/              หน้าของเจ้าของหอ + actions.ts (server actions)
src/app/tenant/             หน้าของผู้เช่า + actions.ts (ยืนยันการชำระแบบสาธิต)
src/components/             UI ที่ใช้ร่วมกัน (PromptPayModal, BillDetail, กราฟ ฯลฯ)
```
